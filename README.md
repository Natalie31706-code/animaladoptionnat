# Animal adoption center

### Project Overview
A responsive animal adoption website built with HTML, CSS, and JavaScript, featuring user registration and login with validation rules for account information and password requirements. The website allows users to browse available animals and explore adoption-related information through a clean and responsive user interface.


### Live Demo
[View the Website](https://animaladoptionnat.vercel.app/login.html)
### Video Preview
[Watch the Website Demo](https://youtu.be/JPtCBnvwaX0)


## Key Features

- Create a user account
- Log in with registered account credentials
- Validate email and password inputs
- Apply password requirements during registration
- Display validation messages for incorrect information
- Browse available animals
- Explore adoption-related information
- Responsive design
  

## Technologies Used
`HTML5` `CSS3` `JavaScript` `CSS Grid` `CSS Animations` `Local Storage` `Git & GitHub` `Vercel`

## Installation
1. Clone the repository
```bash
git clone https://github.com/Natalie31706-code/animaladoptionnat.git
```

2. Navigate to the project folder
```bash
cd animaladoptionnat
```

3. Open index.html in your web browser.
   

## Project Purpose
This project was built to practice and demonstrate core front-end web development concepts using HTML, CSS, and JavaScript while creating a responsive animal adoption website. It focuses on implementing user registration and login functionality, form validation, password requirements, browser-based data storage, and interactive animal adoption content in a clean and user-friendly interface.
